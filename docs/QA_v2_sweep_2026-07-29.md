## Minor observations

1. **Automation note:** Playwright `page.fill()` on the `input[type="number"]` `price-per-session` field did not update React controlled state, leaving the **Save** button disabled. This was a test-driver issue, not a product issue; manual interaction and console-driven `click()` of the populated button saved the rate correctly. The rate persisted after reload.
2. **Currency display:** Live `Intl.NumberFormat("en-NZ", { currency: "NZD", style: "currency" })` rendered `$50.00` (no `NZ` prefix) in the staging Chromium context. This is consistent with browser locale behavior and not a defect; unit tests use the same formatter.
3. **Day-selector header:** On athlete `/today`, selecting a future day updates the page heading to that day (e.g. "Friday, July 31, 2026") while the route stays `/today`; this is the intended client-side date-pivot behavior.
